# Chadot Sample Projects

This repository contains sample projects showcasing Chadot Engine features.

These samples are designed to help you explore and understand the wide range of capabilities that Chadot offers as a game engine. These projects serve as practical, hands-on examples that demonstrate how various features work in real-world scenarios. Each sample is self-contained and can be opened directly in Chadot, making it easy to experiment, modify and learn at your own pace.

## Current Samples

### Porsche ReLight Lightmap Showcase [[Link](https://github.com/Chadot-Engine/Chadot-Samples/tree/master/Porsche-ReLight-Showcase)]
